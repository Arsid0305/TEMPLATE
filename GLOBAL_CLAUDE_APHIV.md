# Глобальные правила для Claude

## ⛔ ГЛАВНОЕ ПРАВИЛО — НИКАКИХ ИЗМЕНЕНИЙ БЕЗ СОГЛАСОВАНИЯ

**Claude вносит изменения в код ТОЛЬКО если:**
1. Пользователь явно описал задачу
2. Claude объяснил что именно будет менять
3. Пользователь подтвердил («делай», «да», «ок» или аналог)

**Запрещено:**
- Менять логику, которую не обсуждали
- «Заодно» исправлять что-то ещё при выполнении задачи
- Откатывать или переписывать ранее сделанное без явной просьбы
- Добавлять фичи, рефакторинг, «улучшения» по своей инициативе

**Если Claude замечает баг или улучшение — он сообщает об этом и ждёт разрешения. Не трогает.**

## Автоматизация проекта (проверять при старте)

При начале работы с новым проектом — проверить наличие цепочек автоматизации. Если файлов нет — предложить создать (одним вопросом), после подтверждения создать всё сразу:

### Что Claude создаёт сам (файлы в репо):
- `.github/workflows/automerge.yml` — любая ветка → `dev` (без проверок, авто)
- `.github/workflows/promote.yml` — `dev` → `main` (только после `npm ci && npm run build`)
- `.github/workflows/deploy.yml` — автодеплой Supabase Edge Functions при изменении `supabase/functions/**`

Схема: `feature/claude/cursor ветки` → `dev` (копится) → `main` (деплой) → Vercel

### Design System (в каждом проекте):
Репо `github.com/Arsid0305/design-system` — отдельный репо, наполняется через отдельный дизайн-процесс (не Claude кода). Внутри — папка для каждого проекта (`/kino-app/`, `/wb-bot/` и т.д.).
Подключается как git submodule — локальное имя папки смотреть в `.gitmodules` проекта.
Перед чтением файлов: `git submodule update --init` (если не инициализирован).
Обновить до последней версии: `git submodule update --remote`.
Claude только **читает** из него перед UI-правками. Не выдумывать UI — брать классы и токены из design system.

### Что требует ручных шагов от пользователя:
- **GitHub Secret `SBP_ACCESS_TOKEN`** — нужен для деплоя Edge Functions. Сообщить когда: первый раз появляется `supabase/functions/` в проекте.
- **GitHub Secret `SUPABASE_PROJECT_REF`** — ID проекта Supabase. Сообщить когда: то же самое.
- **Vercel** — подключить репо вручную на vercel.com. Сообщить когда: первый деплой фронтенда.

### Правило:
Не сообщать обо всём сразу в начале. Сообщать о нужном шаге **в момент когда он впервые становится актуальным**. Коротко: что нужно сделать и где.
