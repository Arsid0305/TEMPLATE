# Правила для каждого нового проекта

## ⛔ ГЛАВНОЕ ПРАВИЛО — НИКАКИХ ИЗМЕНЕНИЙ БЕЗ СОГЛАСОВАНИЯ

**Claude вносит изменения в код ТОЛЬКО если:**
1. Пользователь явно описал задачу
2. Claude объяснил что именно будет менять
3. Пользователь подтвердил («делай», «да», «ок» или аналог)

**Запрещено:**
- Менять логику, которую не обсуждали
- «Заодно» исправлять что-то ещё при выполнении задачи
- Откатывать или переписывать ранее сделанное без явной просьбы
- Добавлять фичи, рефакторинг, «улучшения» по своей инициативе

**Исключение:** баг внутри уже согласованного скоупа — чини сам, сообщи после.

**Заметил баг или улучшение за пределами задачи — сообщи и жди разрешения. Не трогай.**

## Рабочий процесс (в каждом проекте)

### Начало чата
1. Прочитать `CLAUDE.md` проекта
2. Прочитать `tasks/lessons.md` — усвоить паттерны прошлых ошибок

### Получение задачи
1. Определить: BIG или SMALL?
2. **BIG:** написать план в `tasks/todo.md` → провести review → ждать «делай»
3. **SMALL:** краткий план 2-3 строки → ждать «делай»
4. Делать строго то, что обговорили

### Завершение задачи
1. Проверить что работает
2. Обновить чекбоксы в `tasks/todo.md`
3. Коммит + пуш

### Конец чата
1. Обновить «Открытые баги» в `CLAUDE.md`
2. Если пользователь делал правки — записать паттерн в `tasks/lessons.md`

## GitHub Actions — шаблоны

### automerge.yml
```yaml
name: Auto-merge feature branches

on:
  push:
    branches-ignore:
      - main
      - dev

jobs:
  automerge-to-dev:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Merge into dev
        run: |
          git config user.email "actions@github.com"
          git config user.name "GitHub Actions"
          git checkout dev || git checkout -b dev
          git merge --no-ff ${{ github.ref_name }} -m "Auto-merge ${{ github.ref_name }} into dev"
          git push origin dev
```

### promote.yml
```yaml
name: Promote dev to main

on:
  push:
    branches:
      - dev

jobs:
  promote:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          token: ${{ secrets.GITHUB_TOKEN }}

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'npm'

      - name: Install & build
        run: npm ci && npm run build

      - name: Merge dev into main
        run: |
          git config user.email "actions@github.com"
          git config user.name "GitHub Actions"
          git checkout main
          git merge --no-ff dev -m "Promote dev to main"
          git push origin main
```

### deploy.yml
```yaml
name: Deploy Supabase Functions

on:
  push:
    branches:
      - main
    paths:
      - 'supabase/functions/**'

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: supabase/setup-cli@v1
        with:
          version: latest
      - run: supabase functions deploy --project-ref ${{ secrets.SUPABASE_PROJECT_REF }}
        env:
          SUPABASE_ACCESS_TOKEN: ${{ secrets.SBP_ACCESS_TOKEN }}
```
